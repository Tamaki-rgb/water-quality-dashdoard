# 💧 Качество воды: аналитика и прогноз

Учебный веб-дашборд на Streamlit для анализа и прогнозирования качества
воды реки **Сайрамсу** (Сайрамский район, Шымкентская область, Казахстан).

## О проекте

Проект показывает полный аналитический цикл: от очистки сырых данных до
математического моделирования и прогноза временного ряда.

- **Обзор** — ключевые метрики, динамика индекса загрязнения, рейтинг станций.
- **Аналитика** — временные ряды, сезонность (boxplot по месяцам), корреляции
  между показателями, распределения по станциям.
- **Карта** — интерактивная карта станций мониторинга (Plotly), цвет точки =
  уровень загрязнения, клик по точке открывает карточку с показателями.
- **Мат.модель** —
  1. регрессия «индекс загрязнения ~ гидрохимические факторы»
     (линейная регрессия / Random Forest, метрики R² и MAE);
  2. численное решение уравнения адвекции-диффузии-реакции
     (перенос загрязнителя вдоль русла) методом конечных разностей,
     с анимацией C(x,t) и интерактивными слайдерами параметров.
- **Прогноз** — прогноз индекса загрязнения на 7/30/90 дней вперёд
  (ARIMA + регрессоры Фурье для годовой сезонности), с доверительным
  интервалом и метриками бэктеста (MAE, RMSE, MAPE).
- **Выводы** — где хуже всего, когда пик загрязнения, рекомендации, источники.

## О данных

Реальных открытых временных рядов гидрохимии именно по реке Сайрамсу в
публичном доступе не найдено:

- **Казгидромет** ведёт официальный мониториг качества поверхностных вод,
  но публикует данные в PDF-бюллетенях, не в открытом машиночитаемом виде.
- **data.egov.kz / stat.gov.kz** дают только агрегированную статистику по
  регионам и годам, без рядов по конкретным постам.
- **Kaggle / WHO / UNEP** содержат датасеты по качеству воды, но не по
  Казахстану и не по малым горным рекам ЦА.

Поэтому в проекте используется **синтетический датасет**
(`data/water.csv`, генерируется модулем `src/load.py`), физически
откалиброванный под горную реку предгорий Таласского Алатау:
5 станций вдоль русла, 2019–2024 гг., шаг 3 дня, с сезонностью
(снеготаяние, летняя жара), антропогенным градиентом вниз по течению,
шумом, редкими выбросами и пропусками — для отработки полного цикла
очистки и анализа данных.

Нормативы, использованные при калибровке индекса загрязнения (WQI) —
из методик **WHO Guidelines for Drinking-water Quality** и **СанПиН РК**.

### Структура данных (`data/water.csv`)

| Колонка | Описание |
|---|---|
| `date` | дата измерения |
| `station_id`, `station_name` | ID и название станции |
| `lat`, `lon`, `distance_km` | координаты и расстояние от истока |
| `temp_water` | температура воды, °C |
| `ph` | водородный показатель |
| `do_mg_l` | растворённый кислород, мг/л |
| `nitrates_mg_l` | нитраты, мг/л |
| `turbidity_ntu` | мутность, NTU |
| `discharge_m3s` | расход воды, м³/с |
| `bod5_mg_l` | БПК5, мг/л |
| `pollution_index` | индекс загрязнения 0–1 (рассчитывается в `load.py`) |

## Установка и запуск

```bash
# 1. Создать виртуальное окружение (опционально, но рекомендуется)
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить дашборд
streamlit run app.py
```

При первом запуске, если `data/water.csv` отсутствует, он будет
автоматически сгенерирован модулем `src/load.py`.

Пересобрать датасет вручную:

```bash
python src/load.py
```

## Методы и модели

| Задача | Метод | Библиотека |
|---|---|---|
| Индекс загрязнения (WQI) | взвешенное среднее нормированных суб-индексов | pandas / numpy |
| Очистка выбросов | межквартильный размах (IQR) по каждой станции | pandas / numpy |
| Регрессия загрязнения | линейная регрессия / Random Forest | scikit-learn |
| Перенос загрязнителя | уравнение адвекции-диффузии-реакции, явная схема FTCS | numpy / scipy |
| Прогноз временного ряда | ARIMA + регрессоры Фурье (годовая сезонность) | statsmodels |

### Математическая модель переноса загрязнителя

$$\frac{\partial C}{\partial t} = D \frac{\partial^2 C}{\partial x^2} - u \frac{\partial C}{\partial x} - kC$$

где `C(x,t)` — концентрация загрязнителя, `D` — коэффициент турбулентной
диффузии, `u` — скорость течения, `k` — константа распада (самоочищение).
Решается методом конечных разностей (явная схема FTCS) с шагом по времени,
подобранным автоматически из условия устойчивости.

## Источники и нормативная база

- Казгидромет — [kazhydromet.kz](https://www.kazhydromet.kz)
- Открытые данные РК — [data.egov.kz](https://data.egov.kz), [stat.gov.kz](https://stat.gov.kz)
- WHO Guidelines for Drinking-water Quality
- СанПиН РК (санитарные нормы качества воды)

## Ограничения проекта

Это учебный проект: используемые данные синтетические, координаты станций
и точные значения параметров — иллюстративные, не являются официальными
измерениями. Для практического применения необходима замена датасета на
реальные ряды измерений (например, при получении доступа к первичным
данным Казгидромета).
